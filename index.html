GETTING STARTED

Install a bookmarklet

  1. Tap the copy button on the bookmarklet card you want to install.
  2. Create a new bookmark in your browser and give it the same name as the tool.
  3. Edit that bookmark and paste the copied text into its URL / address field instead of the normal website address.
  4. Open a webpage where you want to use the tools, then tap your saved bookmark.

On iPad, editing a bookmark's address may be tucked inside the browser's Bookmarks menu. Some websites block bookmarklets, and browser security rules can limit clipboard or script access.
