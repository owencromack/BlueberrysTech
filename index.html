GETTING STARTED

Install Page Toolkit

  1. Tap Copy bookmarklet on this page.
  2. Create a new bookmark in your browser and name it Page Toolkit.
  3. Edit that bookmark and paste the copied text into its URL / address field instead of the normal website address.
  4. Open a webpage where you want to use the tools, then tap your saved Page Toolkit bookmark.

On iPad, editing a bookmark's address may be tucked inside the browser's Bookmarks menu. Some websites block bookmarklets, and browser security rules can limit clipboard or page access.
